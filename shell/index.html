勾选「动效」= 减少动画：禁用模态 / 面板 / 菜单的过渡动画（系统「减少动态效果」偏好自动生效）。
格式：修饰键（Ctrl / Shift / Alt）+ 键名，如 Ctrl+Shift+F；支持字母、数字、F1–F24 与 / - , . ; [ ] 等符号键；留空表示解绑。跳转定义的 F12 与 Ctrl+点击固定保留。
日志写入数据根的 logs/opencharm.log，单文件超过 1 MiB 自动轮转。关闭「启用日志」后仍会记录错误级日志。
uv 缓存默认与其他项目通过硬链接共享；深度清理后已装环境不受影响，但重装包将重新落盘。uv 位置由用户自有环境变量（UV_CACHE_DIR 等）决定，OpenCharm 不代管。
迁移 = 复制数据到目标并写入数据根指针文件（位于系统配置目录，仅几十字节），重启后生效。uv 缓存/工具目录由你的环境变量（UV_CACHE_DIR / UV_TOOL_DIR）自行管理，OpenCharm 不代管。旧目录不会被自动删除，重启确认无误后可手工删除。
