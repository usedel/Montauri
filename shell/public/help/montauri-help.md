## 快速开始

### 第一次启动

首次启动时若缺少必要工具（`uv`、静态分析引擎），Montauri 会弹出**环境引导**确认框，可一键安装到用户目录，不影响系统环境。不安装也能编辑代码，但装包、环境管理与静态诊断能力会缺席。

### 三步跑通第一个程序

**第 1 步 · 新建项目**

顶部菜单 **文件 → 新建项目**，或欢迎页的「新建项目」按钮。

- **位置**：项目落在哪个目录；
- **Git**：可勾选初始化 Git 仓库；
- **环境类型**：uv 管理的虚拟环境（推荐）或系统解释器；
- **Python 版本**：本地没有合适版本也不怕，uv 会自动下载安装。

已有项目直接走 **文件 → 打开工作区**（`Ctrl+K Ctrl+O`），或用 **文件 → 克隆仓库** 从远端拉取。

**第 2 步 · 运行脚本**

打开任意 `.py` 文件后，任选一种：

| 方式 | 入口 |
|---|---|
| 标题栏运行组 | 右上角 ▶ 按钮（悬停显示键位） |
| 菜单 | **运行 → 运行脚本** |
| 快捷键 | `Ctrl+F10` 运行脚本 · `Ctrl+Shift+F10` 运行项目 |
| 编辑器 gutter | 行号左侧的 ▶ 小箭头（运行光标所在文件） |

输出显示在底部运行控制台；traceback 里的 `File "…", line N` 可点击直接跳转。

**第 3 步 · 下断点调试**

1. 在目标行行号左侧**单击**出现红色断点；右键断点可加条件、命中次数或 Logpoint；
2. 按 `F5` 启动调试；
3. 断下后：`F10` 单步跳过 · `F11` 单步进入 · `Shift+F11` 单步退出 · `Alt+F9` 运行到光标 · `Alt+F8` 求值表达式；
4. 左侧调试侧栏查看调用栈、变量、断点列表；底部**调试控制台**可交互求值。

### 五件值得立刻一试的能力

| 能力 | 入口 |
|---|---|
| 开发工具箱（JSON、正则、时间戳、HTTP 请求…） | `Ctrl+Shift+T` |
| Search Everywhere（文件 / 符号 / 命令混搜） | 双击 `Shift` |
| Live Templates 代码模板 | `Ctrl+J` 面板 · `Ctrl+Alt+T` 环绕选区 |
| 端点视图（FastAPI / Flask 项目自动出现） | 侧栏「端点」视图 |
| 依赖健康体检 | 状态栏体检图标 / 侧栏依赖健康视图 |

## 界面总览

### 顶部标题栏

自绘标题栏，从左到右：

- **品牌标 + 菜单栏**：文件 · 编辑 · 视图 · 前往 · 运行 · Git · 工具 · 帮助；
- **运行组**：运行脚本 ▶ · 运行项目 ▶▶ · 停止 ⏹ · 运行配置 ⚙；
- **调试** · **设置** 图标按钮；
- 右侧：最小化 / 最大化还原 / 关闭窗口按钮。

菜单支持键盘漫游：`←` `→` 切换一级菜单，`↑` `↓` 选择条目，`Enter` 执行，`Esc` 关闭。

### 活动栏与侧栏

左侧活动栏（竖排图标）对应 8 个侧栏视图，点击切换：

| 视图 | 说明 |
|---|---|
| 文件 | 工作区文件树 + 大纲（OUTLINE）；大纲折叠态会记住 |
| 搜索 | 全局搜索（内容检索，支持筛选） |
| TODO | 自动收集项目中的待办标记 |
| 端点 | FastAPI / Flask 路由端点列表（切到该视图才扫描） |
| Git | 变更、分支、历史 |
| 调试 | 调用栈 / 变量 / 断点 / Watches |
| 数据库 | SQLite 连接与表浏览 |
| 运行时 | 运行时热点（读运行采样数据） |

> 侧栏视图按需加载：TODO、端点、数据库、运行时都是**切到该视图才做 IO**，不会拖慢启动。

### 编辑区

- 中央 Monaco 编辑器，支持多标签（可拖拽排序、循环切换）；
- 只读预览类 Tab：**Markdown 预览**、**CSV 数据查看器**、**数据库查询 Tab**、**Diff**——与主编辑器互斥显示；
- 右上角悬浮按钮：Markdown 预览开关、预览模式切换、导出 HTML；
- 面包屑（breadcrumbs）显示当前光标所在符号路径。

### 底部面板

- **运行控制台 / 终端**：PTY 真实终端，支持多会话；
- **问题面板**（`Alt+0`）：错误与警告列表；
- **引用面板**（`Alt+F7`）：查找引用结果；
- **调试控制台**：调试期交互求值。

底部面板用 `Alt+F12` 显隐，侧栏用 `Ctrl+Shift+F12` 显隐。

### 状态栏

显示解释器 / 虚拟环境切换入口、LSP 引擎状态、依赖健康体检图标、光标位置、缩进等。点击解释器区域可快速切换 Python 环境。

## 编辑器与代码智能

### 补全

补全由四层合并而成，候选顺序固定：

1. **智能 Live Template**（最高优先）
2. **运行时观测（intel）**——基于实际运行采样得到的类型与属性
3. **静态分析（pyrefly / basedpyright）**
4. **关键字**

触发方式：

- 输入时自动弹出；
- `Alt+/` 手动触发（中文输入法会吞掉 `Ctrl+Space`，故提供此备选键）；
- `Ctrl+Shift+J` 强制全显（忽略成员访问门控，展示全部模板）；
- `Tab` 接受当前聚焦候选（替换模式：`Enter` 插入 / `Tab` 替换）。

字符串字面量处还会给出**路径补全**（如 `open("...")`、`Path("...")` 等常见调用）。

### 跳转与引用

| 操作 | 快捷键 |
|---|---|
| 跳转定义 | `Ctrl+B`（`F12` / `Ctrl+点击` 固定保留） |
| 查找引用 | `Alt+F7`（完整列表落底部「引用」面板；`Shift+F12` 为快速预览） |
| 重命名符号（跨文件） | `Shift+F6`（`F2` 为同一入口） |
| 转到文件内符号 | `Ctrl+F12` |
| 转到文件 | `Ctrl+Shift+N` |
| 转到行 / 列 | `Ctrl+G` |

重命名采用**就地改名**：锚定符号后以 ghost 预览，确认后跨文件一次性写入。对 Pydantic 模型字段，pyrefly 的 references 为 0，Montauri 会额外扫描 `Model(field=` 构造调用点并入编辑集（扫描 2 秒超时自动降级）；basedpyright 引擎下由引擎自身覆盖，自研层自动旁路。

### Hover 与内联提示

- **Hover**：函数显示观测到的参数 / 返回值 / 异常聚合；变量显示推断类型与常见键（仅类型标签与结构指纹，不展示实际值）；
- **内联诊断**（借鉴 Error Lens）：错误 / 警告直接显示在对应行尾，带 `+N` 折叠；
- **代码引用 CodeLens**、**正则 / 格式串 / JSON 字面量 CodeLens**：在字面量上方给出可点击的操作入口。

### 编辑操作

| 操作 | 快捷键 |
|---|---|
| 行注释开关 | `Ctrl+/` |
| 块注释开关 | `Ctrl+Shift+/` |
| 复制行 / 选区 | `Ctrl+D` |
| 删除行 | `Ctrl+Y` |
| 行 / 选区上移 | `Ctrl+Shift+↑` |
| 行 / 选区下移 | `Ctrl+Shift+↓` |
| 扩大选区（语法感知） | `Ctrl+W` |
| 缩小选区（语法感知） | `Ctrl+Shift+W` |
| 切换列选择模式 | `Alt+Shift+Insert` |
| 折叠全部 | `Ctrl+Shift+-` |
| 展开全部 | `Ctrl+Shift+=` |
| 括号匹配跳转 | `Ctrl+Shift+\` |
| 格式化文档 | `Shift+Alt+F` |
| Optimize Imports（整理导入） | `Ctrl+Alt+O` |
| 向右分屏 | `Ctrl+\` |

### Live Templates 代码模板

内置常用 Python 模板（含爬虫场景分组），支持：

- `Ctrl+J` 打开模板面板；
- 选中代码后 `Ctrl+Alt+T` 环绕模板；
- 补全弹窗中直接插入（最高优先级）；
- 自定义模板：**设置 → 模板** 分类，可新建 / 编辑 / 分组 / 启停 / 导入导出。

### Python 库特别支持

针对常见库的专项体验：

| 场景 | 能力 |
|---|---|
| `re` 正则 | Hover 逐 token 解释；`Ctrl+Alt+R` 在正则测试器中打开 |
| 格式串 | strftime / logging / format 码表预览（工具「格式串预览」） |
| JSON | 字面量 CodeLens；JSON → Python 模型；JSONPath 提取 |
| 表达式求值 | 编辑器内对表达式就地求值（求值桥） |
| 脚本参数 | 运行脚本时通过参数表单填写命令行参数 |

## 运行与终端

### 运行方式

| 方式 | 说明 | 快捷键 |
|---|---|---|
| 运行脚本 | 运行当前文件 | `Ctrl+F10` |
| 运行项目 | 按项目入口运行 | `Ctrl+Shift+F10` |
| 运行选区 / 行 | 只运行选中代码或当前行 | `Alt+Shift+E` |

| 停止 | 停止当前运行 | `Ctrl+F2` |

运行环境由外壳注入：自动前置 `PYTHONPATH` 指向探针包并设置 `MONTAURI_PROBE_AUTOSTART=1`，从而开启运行时采样（不设置则零介入）。

### 运行配置

**运行 → 运行配置** 可管理每个项目的运行配置（入口脚本、参数、环境变量、工作目录等）。配置随工作区持久化。

### 运行控制台

- 统一 PTY 真实终端，支持 ANSI 颜色与交互输入；
- 支持多实例并行运行，运行历史按实例归属；
- 终端内提示文案支持中英文切换。

### 运行历史

`Ctrl+Shift+R` 打开运行历史，回看历次运行的输出与状态。

### 脚本参数表单

运行需要命令行参数的脚本时，参数表单会收集参数并拼装命令行，避免手写一长串参数。

### 草稿文件（Scratch）

`Ctrl+Alt+Shift+Insert` 新建草稿文件，用于快速试验代码片段。草稿支持 `# %%` 单元格执行（`Ctrl+Enter`）。为保持轻量，草稿解释器会话**按需启动、可显式关闭、空闲即回收**。

## 调试

调试基于 debugpy（随应用打包分发，零安装、零网络、切换 venv 无感）+ 自研轻量 DAP 桥。

### 基本流程

1. 行号左侧单击下断点（红点）；
2. `F5` 启动调试 / 继续；
3. 断下后使用单步与求值。

| 操作 | 快捷键 |
|---|---|
| 启动调试 / 继续 | `F5` |
| 停止调试 | `Shift+F5` |
| 单步跳过 | `F10` |
| 单步进入 | `F11` |
| 单步退出 | `Shift+F11` |
| 运行到光标处 | `Alt+F9` |
| 求值表达式 | `Alt+F8` |

### 断点

- **普通断点**：单击行号左侧；
- **条件断点**：右键断点 → 编辑条件，如 `i > 10`；
- **命中次数**：如 `>3`，第 N 次命中才停；
- **Logpoint**：如 `i={i}, url={url}`，不中断只打印；
- **启用 / 禁用**：禁用后保留断点与全部属性，但不下发调试器（灰点）；
- **删除 / 转普通断点**：右键菜单。

断点随工作区持久化。

### 调试侧栏与控制台

- **调用栈**：当前线程的栈帧列表，点击切换帧；
- **变量**：当前帧变量树；
- **Watches**：自定义监视表达式；
- **断点列表**：全部断点的集中管理；
- **调试控制台**：交互式求值（`Alt+F8` 快捷聚焦）；
- **内联值**：调试时在代码行尾直接显示变量值。

## 运行时洞察

这是 Montauri 区别于普通编辑器的核心差异化能力：在**实际运行**中采样类型与结构，再据此增强补全、Hover 与签名帮助。

### 运行时采样（probe）

运行脚本时，探针以 PEP 669 `sys.monitoring` 做**发现窗口 + 局部事件 + 降采样**，把运行时观测写入 SQLite trace 库。原则：

- 观测只记录**紧凑类型表示**（如 `dict[str, int]`）与结构指纹，**绝不记录实际值**；
- 采样开销受红线约束（< 1.5x）；
- 探针失败只打警告，不改写用户进程退出码；
- 未设置 `MONTAURI_PROBE_AUTOSTART=1` 时零介入。

### 运行时补全与提示（intel）

运行时智能 LSP（`montauri-intel`）只读 trace 库建索引，提供补全、跳转、Hover、签名帮助等。特点：

- 数据来自真实运行，**未运行过的代码路径不会有运行时观测**；
- 观测到新鲜类型会覆盖陈旧观测（含降权策略）；
- 与静态引擎四层合并，运行时层优先于静态层。

> 能力边界：运行时补全的准确性以自有样例集自测为准，**未与 PyCharm 做过横向对比**。任何对比结论都必须限定在「自有样例集」范围内。

### 运行时热点视图

侧栏「运行时」视图展示运行热点。下半区显示**未被观测到运行**的代码——注意这是「本次未观测到」，**不等于死代码**。

### 性能模式（Profiler）

内置 Profiler 以「性能模式」形态提供，**默认关闭**，需要时显式开启。开启后可查看耗时视角，帮助定位热点函数。

### 端点视图

FastAPI / Flask 项目会自动出现「端点」视图，列出路由端点，支持跳转到定义、查看请求样例、以及 handler 与 route 之间的反向跳转（CodeLens）。OpenAPI 面板可预览接口定义。

## 环境与依赖

### Python 解释器与虚拟环境

- 状态栏解释器区域可快速切换 Python 环境；
- 支持创建 `.venv`、选择系统解释器或 uv 托管解释器；
- 环境缺失时给出引导（一键安装）。

### 依赖管理

Montauri 所有「安装」按钮内部都走 **uv**。速查：

| 你习惯的 pip 命令 | Montauri 推荐 | 说明 |
|---|---|---|
| `pip install requests` | `uv add requests` | 写入 pyproject 声明 + 更新 uv.lock |
| `pip install requests`（不写声明） | `uv pip install requests` | 语法同 pip，更快 |
| `pip install -r requirements.txt` | `uv pip install -r requirements.txt` | 兼容旧项目 |
| `pip list --outdated` | `uv pip list --outdated` | 查看过期包 |
| `python main.py` | `uv run main.py` | 自动按声明同步环境 |

> 终端里敲 pip 也能用，只是慢且不写声明。

### 依赖健康

- **依赖体检**：分析依赖风格、声明与安装的一致性；
- **修复动作**：对可自动修复的问题给出一键修复；
- **忽略清单**：把已知可接受的问题加入忽略；
- **入口**：状态栏体检图标、侧栏依赖健康视图。

### 存储与磁盘

**设置 → 存储** 分类可查看占用统计，并清理 trace 库、WebView 缓存、uv 缓存等；支持数据迁移与首启落位提示。

## 常见问题

**Q：中文输入法下 `Ctrl+Space` 没弹出补全？**
中文 IME 会吞掉 `Ctrl+Space`（系统级冲突）。用 `Alt+/` 触发补全建议。

**Q：首次启动数据放在哪？**
**帮助 → 打开数据目录** 可直接定位。设置、缓存、日志、trace 库都在里面，首次启动有落位提示。

**Q：uv 缺失会怎样？**
首次使用会弹工具链引导，一键安装 uv 与静态引擎。不装也能编辑代码，但装包与环境管理能力会缺席。

**Q：终端里直接用 pip 行不行？**
行，能用。但推荐 `uv add` / `uv pip install`——更快，且 `uv add` 会写入项目声明。

**Q：怎么回到欢迎页 / 新手指南？**
**帮助 → 欢迎页**（随时可回）；**帮助 → 新手指南** 打开三分钟上手指南。

**Q：运行时补全为什么没给出候选？**
运行时数据来自**实际运行采样**——没跑过的代码路径不会有观测。先运行一次脚本，再回到编辑器查看。

**Q：运行热点里显示「未观测到运行」，是不是死代码？**
不是。那只表示**本次未观测到**，不代表该代码永不执行。

**Q：Markdown 文件为什么打开的是预览而不是编辑器？**
默认按预览打开，可在 **设置 → 编辑器 → Markdown 打开方式** 改为编辑或分屏；预览 Tab 上也有「编辑源码」按钮。

**Q：某个静态诊断不想要怎么办？**
部分诊断（如 Pydantic 构造校验）可在 **设置 → 编辑器** 中关闭；Ruff 提示支持 `# noqa` 抑制。

**Q：快捷键能改吗？**
能。**设置 → 快捷键** 按功能分组展示全部键位，可逐条自定义。

## 数据目录与日志

### 数据目录

**帮助 → 打开数据目录** 可打开数据根，其中包含：

- `settings.json`：应用设置；
- `logs/`：日志；
- `docs/`：由应用写入的文档（含本帮助文档、新手指南、插件作者指南）；
- `traces/`：运行时 trace 库（按项目 hash 命名）；
- `plugins/`：插件目录；
- `runtime/`：自研组件与调试器运行位置。

### 日志

统一日志工具，**设置 → 日志** 可配置：

| 字段 | 默认 | 说明 |
|---|---|---|
| 启用日志 | 开 | 总开关（关闭后仅 error 落盘） |
| 日志级别 | `info` | `error` / `warn` / `info` / `debug` |
| 保留份数 | 3 | 单文件超 1 MiB 自动轮转 |
| 输出 stdout | 关 | 是否同时输出到标准输出 |

排查线上问题：把级别调到 `debug`，或用 **帮助 → 打开日志目录** 直接定位日志文件。日志落盘位置固定为用户主目录下的 `~/.montauri/logs/montauri.log`。

### 隐私

- 运行时采样**只记录类型标签与结构指纹，绝不记录实际值**；
- 所有数据默认保存在本机用户目录，不上传；
- 遥测与网络请求仅在用户主动操作（如 HTTP 工具、Git 远程、克隆）时发生。
